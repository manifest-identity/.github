# manifest-identity

This organization holds the name for manifest-identity, the
intended-access source of truth: what each identity is supposed to
hold, who said so, and when. It is the companion to role-call, which
reads what identities actually hold; the difference between the two is
the product.

The project is in its design phase and lives at
https://github.com/tltaylor1/manifest-identity. It is part of
control-plane, a security engineering program built in public:
https://tltaylor1.github.io.
